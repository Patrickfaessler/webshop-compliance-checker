# A5 Keyboard Operation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rule A5 checks keyboard operation (unreachable, no-focus-style, keyboard-trap, not-focusable) on a page-type
sample (default) or on all pages (form option, 10 min limit), with a user-settable Tab limit.

**Architecture:** The crawler runs a keyboard probe in the same tab after DOM, links and axe-core are read, for pages
chosen by a per-crawl sampler, and attaches `rules.KeyboardReport` to `rules.Page`. Rule `a5` only maps those reports
to a result. Scan options travel API → `scan.Scan` → worker → `crawler.Options`; a new `NoteDe` on rule results carries
the "limit reached" note to UI and reports.

**Tech Stack:** Go 1.27, chromedp v0.22 (`Input.dispatchKeyEvent`, `DOMDebugger.getEventListeners`), Flutter 3.47.9.

**Spec:** `docs/superpowers/specs/2026-11-21-a5-keyboard-design.md` (design), `specs/rules/A5-keyboard.md` (rule spec, updated in Task 1).

## Global Constraints

- Spec → test → code. Every test has a `// Spec: <ID>` comment (CLAUDE.md rule 2).
- Code, comments, specs in English; **all user-facing text German** (rule 8).
- **Only the Tab key is pressed.** Never Enter/Space, never click, never submit (rule 6).
- Probe runs **after** DOM/links/axe are read; a probe error never fails the page or the scan.
- Defaults/limits: sample max **5** pages (start, category, product, cart, checkout); Tab limit default **200**, allowed **50–1000**; scan limit **5 min**, mode "alle Seiten" **10 min** (C-1).
- Never "konform"/"tastaturbedienbar" wording (rule 7).
- JSON changes are additive; report `version` stays 1.
- Browser tests use `openOrSkip`/`FindBrowser` and skip without a browser. Run locally with `CHROME_PATH=/usr/bin/chromium`.
- Register A5 in `backend/cmd/api/main.go:132`, `backend/internal/corpus/corpus_test.go` and the e2e lists `internal/e2e/testshops_test.go:65`, `report_test.go:43` and `report_test.go:192` (self-scan: the HTML report itself must pass A5, N7/RP-9).

## Review Focus

1. **Cooldown with other keyboard options:** a repeated request for the same address within the cooldown but with another mode or Tab limit must start a new scan, not return the old sample result. → Task 6, `TestCooldownRespectsKeyboardOptions`.
2. **Slow probe on a big page:** 1000 presses must not kill the page render (20 s page timeout). Probe has its own 30 s budget; on timeout the page keeps its HTML/axe and `Keyboard` is nil. → Task 4, `TestRenderKeepsPageWhenProbeTimesOut`.
3. **Autofocus / focus not at the top:** a page with an `autofocus` field must still be walked from the document start. → Task 4, fixture `autofocus` in `TestProbeKeyboard`.
4. **Hidden controls:** controls in a closed menu (`display:none`, `visibility:hidden`, `[inert]`, `aria-hidden="true"` ancestors, closed `<details>`) are not `unreachable`. → Task 4, fixture `hidden-menu`.
5. **Focus style on the wrapper (`:focus-within`):** a field whose wrapper gets the outline is not `no-focus-style`; the parent's style is compared too. → Task 4, fixture `focus-within`.

  1. Prepare JS: collect visible, enabled candidates (selectors from the Global spec list, excluding `tabindex="-1"`, disabled, hidden per Review Focus 4); snapshot unfocused style of each element and its parent; collect `div/span` with `cursor:pointer` and no role/tabindex (max 100), flag those with `onclick`; `document.activeElement.blur()`, `window.scrollTo(0,0)`, place focus at document start (focus `document.body` via a temporary `tabindex=-1` element at the top of `body`, removed after the first press). Keep state on `window.__a5`.
  2. For the listener check, get each unflagged pointer element's objectId (`Runtime.evaluate` of `__a5.ptr[i]`) and call `DOMDebugger.getEventListeners`; any `click`/`mousedown`/`pointerdown` → `NotFocusable`.

Same idx 3× in a row, or an idx seen before → trap at that element, stop. `!styleChanged` (element and parent snapshots equal) → `NoFocusStyle`.
